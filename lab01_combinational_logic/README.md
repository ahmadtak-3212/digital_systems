# Lab 1: combinational logic

First SystemVerilog design: `assign` statements map four switches and three buttons onto LEDs. It covers OR, 3-input XOR, NAND, a 2-bit add whose carry drives the red LED, and a button-driven RGB channel. `top_tb.sv` is the course's heavily commented starter testbench for checking the input–output relationships.
